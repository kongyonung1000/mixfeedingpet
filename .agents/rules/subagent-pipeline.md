# 3단계 서브에이전트 파이프라인 운영 규칙 (Subagent Pipeline Rules)

이 프로젝트는 산출물의 정확성과 품질을 보장하기 위해 3단계 서브에이전트 협업 파이프라인을 표준 워크플로우로 따릅니다.

## 1. 서브에이전트 역할 정의

### A. 리서치 에이전트 (`researcher`)
- **역할**: 프로젝트 파일, 통계 데이터, 웹 문서 및 외부 자료를 탐색하고 팩트시트를 작성합니다.
- **권한**: Read-only (파일 수정 금지, 탐색 및 분석 전용)
- **산출물**: 사실(Fact) 중심 요약, 수치 비교표, 출처 정보

### B. 작성 에이전트 (`writer`)
- **역할**: 리서치 에이전트의 팩트시트를 기반으로 최종 결과물(보고서, 문서, 코드 등)의 초안을 작성합니다.
- **권한**: Write-tools 허용 (파일 생성, 코드 작성, 문서 편집)
- **산출물**: 완성형 문서 초안 및 작성 의도 요약

### C. 검수 에이전트 (`reviewer`)
- **역할**: 리서치 원본 데이터와 초안을 대조하여 정확성, 완성도, 가이드라인 준수 여부를 평가합니다.
- **권한**: Read-only (독립적이고 엄격한 평가자)
- **산출물**: `[PASS]`(승인) 또는 `[NEEDS_REVISION]`(반려) 판정 및 구체적 수정 지침

---

## 2. 오케스트레이션 실행 프로세스

1. **지시 및 분할**: 메인 에이전트가 사용자 요구사항을 파악하고 리서치 범위를 정의합니다.
2. **리서치 수행**: `researcher`를 호출하여 원천 데이터 검증 및 팩트시트를 생성합니다.
3. **초안 작성**: `writer`에게 리서치 산출물을 전달하여 초안을 생성하도록 합니다.
4. **품질 검수**: `reviewer`가 원본 데이터와 초안을 교차 검증합니다.
   - `[NEEDS_REVISION]`인 경우: 지적 사항을 `writer`에게 전달하여 재작성합니다.
   - `[PASS]`인 경우: 최종 승인 후 사용자에게 전달합니다.
